# Apartado 2.3 · Grupo 17

La versión final para entregar está en **`Entrega_2.3/`**. Contiene el código, las 51 fotografías, la calibración, los resultados, las instrucciones y una única presentación final de 6 diapositivas.

- **Entrega completa:** `Entrega_2.3_Grupo_17.zip`.
- **Presentación final:** `Entrega_2.3/Presentacion_Grupo_17.pptx`.
- **Instalación y ejecución:** `Entrega_2.3/README.md`.
- **Preparar la defensa:** `Entrega_2.3/GUIA_EXPOSICION.md`.

El ZIP contiene únicamente la versión final. `historico/` conserva las versiones anteriores y una copia completa previa a las correcciones, para poder recuperarlas. No forma parte del material para entregar.

La entrega demuestra calibración, corrección de distorsión y detección ArUco sobre fotografías guardadas del robot. Las limitaciones de precisión y la ausencia de validación con fotos independientes están documentadas en el README y la presentación.
